# ThreadBack AI judge demo (about 3 minutes)

Use a separate browser profile. Build with npm run build and load dist through Chrome/Edge Developer mode, or use the web preview for UI-only evaluation. Synthetic data does not prove live clustering quality; the mixed-scenario tests exercise that algorithm separately.

1. Open Dashboard and click **Demo Data**. Explain the three synthetic scenarios: EurekaDev submission, ANC headphones and quantum harmonic oscillator research. EurekaDev has four saved task tabs; the dataset also includes five timeline events.
2. Search headphones, then clear search. Open EurekaDev **Timeline** to show its chronological captured activity. The last event is the Devpost project-edit page.
3. Open **Why?** to show keywords shared by distinct pages, observed queries, actual time span and captured parent links. Read the values currently displayed; do not invent percentages, counts or timing.
4. Open **Graph**. Milestones and remaining steps are inferences from visits, not proof that code was pushed or a form submitted.
5. Click **Resume Task**. In an installed extension it reuses matching open tabs, reopens missing task URLs, and focuses the suggested next-action page. Web preview only demonstrates the briefing. Illustrative demo URLs may require login or be unavailable. The briefing distinguishes selected tabs from successfully reopened tabs.
6. Use the card menu to mark complete/archive, reload, and verify the saved status.
7. Show **Privacy Center**: content extraction and remote AI are unavailable reserved controls; exclusions and deletion work. Explain that metadata is stored locally without application encryption and URLs/titles can contain sensitive data.

The product uses local weighted heuristics and works without a paid AI API. The experimental remote provider adapter is not connected to this workflow.
