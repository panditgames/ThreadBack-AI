# Final submission checklist

## Release
- [ ] Confirm main and the release SHA match the final report; inspect GitHub CI if it was pending.
- [ ] Check final typecheck, lint, test, build, packaging and secret-scan results in HANDOFF.md.
- [ ] Download the release ZIP or use release/ThreadBack-AI-v1.0.0.zip. Extract it; manifest.json must be at the extracted root.
- [ ] In a separate Chrome/Edge profile, open chrome://extensions or edge://extensions, enable Developer mode, Load unpacked the extracted root, pin the icon and open popup/dashboard.
- [ ] Click Demo Data and confirm three threads. Open Why, Timeline and Graph. Resume may open login pages. Installed Chrome/Edge qualification remains a human check.

## Media
- [ ] Record the 2–3 minute take using DEMO_SCRIPT.md; review for personal URLs, bookmarks, avatars, notifications and credentials.
- [ ] Use sanitized release/screenshots/dashboard.png and popup.png if present. Otherwise load Demo Data in the separate profile, close personal tabs, capture dashboard at about 1280×900 and popup at about 380×600. Inspect every image before sharing; label synthetic data honestly.
- [ ] Upload the video and screenshots; replace the explicit placeholders in SUBMISSION.md. Do not invent links.
- [ ] Copy the pitch, features, architecture, evidence, limitations and AI-assistance attribution into the actual submission fields.
- [ ] Include repository https://github.com/panditgames/ThreadBack-AI and the verified release asset link if available.

## Submit yourself
- [ ] Check EurekaDev's actual rules, eligibility, deadline, track and required fields on the platform. None are invented from this repository.
- [ ] Confirm media is viewable by judges and contains no private information.
- [ ] Verify links in the platform preview, attach the installable ZIP if supported, and submit the entry yourself.
- [ ] Save the submission confirmation. This automation does not submit entries or publish to an extension store.
